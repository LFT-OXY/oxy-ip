# 03 — 官方商店更新与官网入口闭环

**What to build:** 商店应用可更新可获取的正式版本资料，点击前往正确官方商店；只有官网入口的应用仍可正常查看并前往官方下载页。

**Blocked by:** 01
**Status:** ready-for-agent
**Impl:** ready

## 验收标准

- [ ] 可获取的官方商店信息按应用与平台对应，不用同一个版本覆盖所有平台。
- [ ] 无法自动获取的商店或官网来源允许人工维护，未知字段留空，不暗示已自动核验。
- [ ] 失败保留已有信息和成功核验时间；来源与入口类型在页面正确呈现。
- [ ] 对有稳定官方更新源的官网应用接入该源；无法可靠自动化的使用规格允许的人工维护方式。
- [ ] 覆盖商店获取成功、无结果及访问失败，以及仅有官网下载页的真实应用展示。

- [ ] 本票相关检查通过，未修改本任务明确排除的功能；UI 变更验证移动与桌面、主题、语言和基本键盘操作。

## 边界

以本任务已确认规格和数据维护决策为准。本票保持待实施，需用户手动触发实施；不自行启动下一张票或发布生产环境。
