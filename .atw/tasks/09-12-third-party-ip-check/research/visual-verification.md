# 卡片对齐修正：验证记录

## 修改边界

源码仅修改 `src/views/components/third-party-ip-check.tsx`：

- 多站分组按成员数量使用桌面三列或两列，单站占满整行。
- 多站卡片采用 CSS Grid 的三行 subgrid，共享站名、用途、提示的轨道；不设固定高度，不增加运行时 JavaScript 测高。
- 单站在桌面将站名、用途、提示入口横向排列；展开后提示移入全宽行，避免长文挤在窄列。
- 沿用原有 `lg` 断点（1024px）；移动端单列堆叠。站点数据、翻译、外链、查询及缓存均不修改。

## 浏览器红绿证据

新增的是依赖本机已有 `playwright-cli` 的单次复查脚本，不安装依赖，不建立浏览器测试框架：

```bash
pnpm build
pnpm preview --host 127.0.0.1 --port 4173 --strictPort
# 在另一终端执行：
node .atw/tasks/09-12-third-party-ip-check/research/check-card-layout.js
```

脚本检查真实页面 DOM，不检查源码类名；在浏览器请求边界使用合成查询响应，其他外站请求被拦截。失败时退出码为 1。

覆盖：两页 × 中英文 × 深浅主题 × 390/1024/1440px 三种宽度 × 全收起/首项展开/全部展开，共 **72** 个组合。
